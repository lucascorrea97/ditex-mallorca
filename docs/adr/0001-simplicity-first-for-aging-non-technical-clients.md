# Simplicity-first UI for aging, non-technical clients

The majority of Ditex's current Clients are older tradespeople who are not comfortable with web apps. We will optimise the whole site — especially the Client Area and Price List — for maximum simplicity and legibility (large text, obvious buttons, minimal steps, no clever interactions that need discovery) over visual richness or density.

## Considered Options

- **Modern, rich, interactive UI** — looks impressive, matches the abandoned `ditex.vercel.app` direction, but risks alienating the exact people who use the site most today.
- **Simplicity-first, progressive enhancement** (chosen) — start from the simplest thing that works for a 60-year-old upholsterer on a phone; layer richer browsing/visuals on top in a way that never blocks the basic task.

## Consequences

- Design reviews judge "can the least tech-savvy client do this without calling us?" before judging aesthetics.
- Richer product visualisation (to attract newer clients / upsell) is welcome, but only as an *additive* layer that doesn't complicate the core "find product, see price" path.
- This does not mean dated or ugly — it means clear. We still build something modern enough to serve the next generation of Clients as older ones retire.
